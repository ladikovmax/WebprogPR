# Лабораторна робота 24

Тема: веб-додаток на React.js.

## Структура

- `cdn/` - реалізація React через CDN-підключення.
- `cra/` - реалізація у форматі Create React App.
- `images/works/` - папка для прикладів робіт з рукоділля.

## Запуск

CDN-версію можна відкрити напряму:

```text
lb24/cdn/index.html
```

CRA-версія запускається з папки `lb24/cra` після встановлення залежностей:

```bash
npm install
npm start
```

Для CRA-зображень додай або скопіюй фото у `lb24/cra/public/images/works`.
